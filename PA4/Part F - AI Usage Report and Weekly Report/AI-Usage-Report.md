## A.3. Independent Work and Verification Methods

**Performed by:** Đào Duy Anh | **Reviewed by:** Trần Huỳnh Mạnh Đạt | **Edited by:** Đào Duy Anh

* **Done entirely by the team, without AI:** final decisions on the PA4 scope, editing and integration of the submitted artifacts, and ownership of the completed documentation, diagrams, chatbot feature, and UI work.
* **How AI-assisted content was edited:** every AI-drafted document was read line by line against the source code before being committed; file names, section structure and the document set were decided by the team; statements the team could not verify were either removed or explicitly marked as unverified in the document itself.
* **Verification methods:** members reviewed AI-assisted drafts and code in the relevant project context. Repository-based documentation was compared with the frontend and backend source; the chatbot work, diagrams, and UI work were reviewed by their responsible members before inclusion in PA4.
* **Commitment:** every figure, count and diagram in the PA4 documents describes the code as it actually exists in the submitted repositories. Where the documentation and the implementation disagree, the disagreement is stated in the document rather than hidden — see §4 of `c4-level3.md` and §"Modeling decisions" of `c4-level1.md`. No simulated or fabricated results were used.
